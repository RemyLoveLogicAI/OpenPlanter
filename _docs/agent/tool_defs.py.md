## Overview

This module provides provider-neutral tool schema definitions and helper functions to convert those definitions into provider-specific shapes used by OpenAI and Anthropic APIs. It centralizes the tool schemas and supplies utilities to adjust and validate those schemas for different modes, including a strict OpenAI mode that enforces required properties and recursive schema fixups, and a utility to remove acceptance criteria from certain schemas.

The exported functions include conversion routines for both OpenAI and Anthropic formats, helpers that perform in-place modifications to schema objects for strict mode, and a small utility to strip acceptance criteria from subtask/execute schemas. The module acts as a single source of truth for tool schemas and the transformations needed to produce API-specific tool arrays for the agent.
