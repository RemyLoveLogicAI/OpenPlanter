## Overview

This directory holds the core modules used by the OpenPlanter agent to coordinate multi-turn agent behavior, centralize system prompt text, and define provider-neutral tool schemas plus helpers to convert them into provider-specific shapes. At the root level there are three Python modules: engine.py which orchestrates agent turns, summarization, and model selection logic; prompts.py which centralizes the system prompt text used by the OpenPlanter agent; and tool_defs.py which provides provider-neutral tool schema definitions and helper functions to convert those definitions into shapes suitable for OpenAI and Anthropic APIs.

Together these modules form the agent layer that sits between higher-level orchestration and provider-specific integration. engine.py drives the runtime decision-making around turn-taking and summarization, prompts.py ensures consistent system prompt content across model interactions, and tool_defs.py provides a single source of truth for tool schemas with conversion helpers so the agent can work with multiple LLM providers without duplicating schema definitions. This allows the rest of the system to rely on a consistent agent interface while delegating provider-specific formatting to tool_defs.py.


### File Organization

Files are organized by responsibility: orchestration (engine.py), content/prompt management (prompts.py), and provider-neutral tool schema + conversion helpers (tool_defs.py). The flat structure keeps agent-related code co-located and easy to find.

## Architecture Notes

- Provider-neutral tool schemas are defined centrally so conversion to multiple provider-specific formats can be implemented in one place (tool_defs.py), reducing duplication.
- The engine module acts as the orchestration entry point driving turns, summarization, and model selection and depends on prompts and tool schema conversion rather than provider-specific details.
