## Overview

This module centralizes the system prompt text used by the OpenPlanter agent. It provides utilities to assemble the full system prompt (including optional recursion sections) and to extract an investigative role tag embedded in an objective string. The file acts as a single source of truth for prompt-related logic so other parts of the engine can request consistent prompt text and role detection behavior.

The two module-level functions cover the primary responsibilities: building the complete system prompt, conditionally including recursion-related sections, and parsing an objective to detect a bracketed role tag. The module contains no classes and exposes these utilities at the module level for straightforward import and use throughout the agent system.
