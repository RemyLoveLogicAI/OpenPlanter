## Overview

This directory is the entry point for the OpenPlanter desktop frontend and contains no top-level source files; all implementation is organized under the src/ subdirectory. The src/ subdirectory holds the frontend source code and is responsible for UI components, command logic (including model-related command behavior), the observable application state, and the primary stylesheet used by the desktop frontend. At the root level there are intentionally no files, which emphasizes that all developer work for this part of the project happens within src/.

Together, the directory's structure groups user interface elements, command-handling code, and shared state into a single focused location so developers can find UI components, command implementations, and styling in one place. This directory serves the larger OpenPlanter desktop system by providing the visual and interactive layer — the components and logic that users interact with — while relying on other parts of the repository for models, backend integration, and packaging. Because all source is under src/, navigating and maintaining the frontend is simplified: add new UI elements, update command behavior, or adjust global styles in that subdirectory.


### File Organization

The repository root for this directory contains no files; all frontend source code and assets are organized under the src/ subdirectory. src/ separates concerns by grouping UI components, command logic, observable application state, and the primary stylesheet into focused folders (as described in the subdirectory purpose). This keeps the top-level frontend folder minimal and enforces a single place for frontend development.
