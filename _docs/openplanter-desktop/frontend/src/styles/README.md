## Overview

This directory contains the main CSS asset used by the desktop frontend: main.css. The root-level stylesheet defines the primary visual layout and component styles for the desktop application, providing the core rules for layout, spacing, typography, component appearance, and any global theming applied across the frontend.

Because this directory is focused solely on styling, it serves as the single authoritative source for the desktop UI's look-and-feel. Changes here affect the entire desktop frontend; developers should use this file to inspect and modify global styles, overrides, and component-level CSS definitions. There are no subdirectories in this styles folder, so all stylesheet concerns for the desktop frontend are centralized in main.css.


### File Organization

A single-file, flat organization: main.css is the sole stylesheet at this level and contains the primary layout and component styles for the desktop frontend. This flat structure centralizes styling for easy discovery and modification.
