## Overview

This directory holds command-related TypeScript modules used by the OpenPlanter desktop frontend. At the root level it includes model.ts, which focuses on model-related command logic, and slash.ts, which exports a single function handleCaseCommand responsible for coordinating application state, invoking an API, and delegating to specialized command handlers. Together these files provide the command-layer glue that interprets higher-level actions and triggers the appropriate model updates and external interactions.

There are no subdirectories in this folder. The two files present work together: model.ts encapsulates command logic tied to the application's data/model concerns, while slash.ts acts as an entry point for a particular family of commands (slash/case commands), mediating between the UI/state, an API invocation, and the specific handlers implemented elsewhere. This directory's role in the larger system is to centralize command orchestration for the desktop frontend so that UI components can call a small set of command entry points which then manage state transitions and API interactions consistently.


### File Organization

Files are placed at the root of this directory in a flat structure: model-related command logic (model.ts) and a single handler entry point (slash.ts). This keeps command orchestration and model-command implementations colocated and easy to find.
