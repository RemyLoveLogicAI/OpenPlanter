## Overview

This TypeScript module defines a simple observable state store and the application state shape used by the front-end. It provides a generic Store<T> class that holds a value, allows getting/setting/updating that value, and supports subscription via listeners that are called whenever the value changes. The file also declares several interfaces describing message and application state structures (ChatMessage, ToolCallDisplay, StepToolCall, AppState) and exports a pre-initialized appState instance of Store<AppState> with default values.

The exposed types capture structured data for chat messages, tool call displays, and step summaries, while appState serves as a singleton global store for provider/model selection, session info, token counts, running state, message history, and various control parameters (e.g., recursion, maxDepth). The module is focused on in-memory state representation and reactive updates through listener callbacks.
