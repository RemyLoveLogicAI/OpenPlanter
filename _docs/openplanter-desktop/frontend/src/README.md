## Overview

This directory contains the frontend source for the OpenPlanter desktop application. At the root there are no top-level source files; all code and assets are organized into focused subdirectories. The commands/ subdirectory implements frontend command logic including model-related command behavior (model.ts) and a top-level slash command handler (slash.ts) that coordinates application state, API calls, and specialized handlers. The components/ subdirectory provides UI-focused modules including ChatPane.ts which implements the chat pane UI logic and InputBar.ts which supplies utility functions used by an input bar component.

The state/ subdirectory provides the observable state store and the TypeScript definition of the application state shape used by the desktop frontend, intended as the canonical application state location. The styles/ subdirectory contains the primary CSS stylesheet main.css that defines layout and component styles for the desktop application. Together, these directories separate concerns: commands handle behavior and orchestration, components implement UI pieces, state centralizes application data, and styles define presentation. This structure supports clear navigation for developers working on model/command behavior, UI implementation, state management, and visual styling without root-level clutter.


### File Organization

Files are grouped by responsibility into subdirectories: commands/ for command logic and orchestration, components/ for UI modules, state/ for the observable application state definition and store, and styles/ for the global CSS. This keeps behavior, presentation, and state separated and makes it straightforward to locate related code.

## Architecture Notes

- Separation of concerns is enforced by directory: commands handle orchestration and business behavior, components handle UI, state centralizes application data, and styles contain presentation rules.
